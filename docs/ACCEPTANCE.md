# 验收标准与证据规范

所有条目当前均为待验证目标。初始化包的文档／脚本检查不等于 ASR 应用验收。

## 1. 证据边界

每份报告记录源代码 commit、应用版本、运行时和模型 revision、macOS 版本、CPU/芯片、内存、音频来源及 SHA-256、测试命令或操作、预期、实际、通过／失败、证据位置。公开报告不包含个人用户名、录音正文、密钥和真实业务文件。

默认使用许可清楚的公开样本、自制非敏感样本或合成安全夹具。测试脚本不得自动扫描个人 Vault。单元测试使用假计算引擎时必须标为 mock；网络被防火墙拒绝和完全没有尝试外连是不同证据。

## 2. 必过测试

| ID | 场景 | 通过要求 |
|---|---|---|
| A01 | 干净 Mac 首装 | 无预装 Python／Homebrew／开发工具即可完成；不要求关闭系统安全保护 |
| A02 | 系统与硬件检测 | 非支持架构阻断并说明；未知组合不显示“已验证可用” |
| A03 | 模型下载 | 来源、字节数、进度和磁盘信息真实；主动批准后开始 |
| A04 | 下载中断和重启 | 同一文件版本安全恢复；远端文件变化或 Range 被忽略时不会拼接坏文件 |
| A05 | 文件损坏与路径攻击 | checksum 错误、路径穿越、符号链接、非法归档被拒绝；旧可用模型不被破坏 |
| A06 | 模型完整后的断网转写 | 启动、模型加载、解码与推理均不依赖联网；缺文件明确报错，不隐式下载 |
| A07 | 本机鉴权与任务归属 | 错误／撤销令牌、陌生客户端、未授权任务读取或取消均拒绝 |
| A08 | 端口被占用和伪造服务 | 不误杀监听者，不把伪造 capabilities 当成可信配对，不泄露凭据 |
| A09 | 中文和含空格路径 | 安装目录、用户名、文件名均能正确处理；不执行拼接 shell 命令 |
| A10 | 短录音与边界输入 | 正常录音、静音、极短音频、空文件、损坏容器均有合理结果；不伪造正文或时间戳 |
| A11 | 真实 30 分钟录音 | 全文件覆盖、无静默截断；人工抽查文本、重复与遗漏 |
| A12 | 真实 2 小时录音 | 资源有界，任务完成或清晰失败；完整实测，不以重复压力音频充当质量证据 |
| A13 | 格式兼容 | 按实际录音场景覆盖 WebM/Opus、M4A/AAC、WAV、MP3；只公开已验证格式 |
| A14 | 取消与退出 | UI 在计算真实结束后才标记取消；取消失败有说明；无孤儿推理进程 |
| A15 | 插件重载 | 恢复同一服务实例任务；源文件改变不会继续错误任务 |
| A16 | 服务崩溃或重启 | 识别实例变化，清晰标记失败；不默默重算造成重复任务 |
| A17 | 多 Vault | 一份运行时、单计算槽；任务所有权隔离；关闭一个 Vault 不影响另一个 |
| A18 | 结果回写失败 | 允许取回已完成结果；未保存成功前不删除服务端结果 |
| A19 | 内存、磁盘不足 | 提交前检查和运行时受控失败；不能生成看似完整的残缺结果 |
| A20 | 空闲、睡眠与电源 | 空闲释放实际模型内存；睡眠前后状态可解释；不把休眠直接误判成功 |
| A21 | 升级与卸载 | 用户批准、忙碌保护、版本验证、回退；不删 Vault 和非本应用缓存 |
| A22 | 插件回归 | 旧云端配置、笔记编辑、转写链接、任务中心和 Memory 不受破坏 |
| A23 | 签名、公证、首启 | 测试真实下载的包，不只测试构建目录；有公证及签名证据 |
| A24 | 诊断与公开仓库隐私 | 日志／ZIP 无音频、正文、令牌和个人路径；仅用户主动导出，无自动上传 |

## 3. 性能与识别质量

记录冷启动与热启动耗时、模型加载耗时、音频时长、转写耗时及 RTF（转写耗时 ÷ 音频时长）。同时记录进程内存、MLX 分配情况、系统内存压力与是否发生 swap；不要仅用 Python 进程 RSS 代替 GPU／统一内存总占用。

有人工参考稿时可报告 CER/WER，注明标点、数字和简繁体归一化规则；没有参考稿时只报告人工抽样发现，不能制造“准确率”。未来说话人分离需独立指标，普通 ASR 文本通过不能说明分离准确。

首轮基准为 M2 / 16GB。最低内存、最低 macOS、处理速度和最长录音的公开承诺均在测试完成后决定。上游模型 card 的测评数字不能直接当成本应用的实测。

## 4. 公开测试版门槛

A01–A24 中与首期已实现功能相关的条目必须完成并逐项留证据；不适用项应解释原因，不能直接算通过。干净首装、鉴权、离线、文本完整性、取消和笔记不被破坏属于阻断项。

如果 2 小时自然录音目标未通过，只能发布明确缩小容量边界的受限预览，不得对外宣传支持 2 小时会议。未完成公证的开发构建不作为面向普通用户的公共测试版。
