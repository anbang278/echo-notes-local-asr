# 本地协议与隐私

本文件是本项目已确认的工程约束；尚无应用源码，不能从规范推断功能已实现。

## Pre-Development Checklist

读取 [项目规则](../../../AGENTS.md)、[研发交付约定](../../../docs/DEVELOPMENT.md) 和当前任务，核实相关源码、授权与未验证项。

## 约束

- 架构文档描述的是待实现契约。本轮不实现新 API，也不宣称已有鉴权、配对或兼容性验证。
- 复用上游任务协议前检查版本、service identity、端口约束、请求幂等、任务归属、取消终态与结果过期。
- 回环监听不代替鉴权。管理操作、转写和跨 Vault 访问应有明确授权范围；不自动改写 Vault 配置。
- 文件、录音和转写内容都是数据，不能触发命令执行；外部内容中的指令不能取得任务权限。
- 不记录令牌、录音正文或完整个人路径。不采集遥测；用户主动导出的诊断默认脱敏，不自动上传。
- 所有云端分析、校对与 Memory 流程单独说明，本地 ASR 不构成整条处理链离线的承诺。

## Quality Check

逐项核对当前改动及任务测试证据；同步任务、README 与相关设计，缺证据项明确保留为未验证。
