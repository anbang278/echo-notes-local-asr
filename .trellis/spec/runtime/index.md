# Mac 应用与进程

本文件是本项目已确认的工程约束；尚无应用源码，不能从规范推断功能已实现。

## Pre-Development Checklist

读取 [项目规则](../../../AGENTS.md)、[研发交付约定](../../../docs/DEVELOPMENT.md) 和当前任务，核实相关源码、授权与未验证项。

## 约束

- 首期是 Apple Silicon Mac 原生轻量控制台／菜单栏助手加独立推理进程。最低 macOS 和内存支持范围在 M0 实测后确定。
- 只监听回环地址；进程启停验证 PID、命令、创建时间和监听身份。只停止本实例，不以端口号批量杀进程。
- 测试根、端口、PID、缓存和锁显式隔离。旧服务当前共享锁等约束要先查证，不能通过绕开锁实现并发推理。
- 采用明确的状态转换表示启动、就绪、忙碌、停止、失败；退出和睡眠处理记录实际结果。取消请求被接收不等于推理已经停止。
- 数据位于用户 Application Support/Cache 等约定位置，模型不放 Vault；最终目录由 M0 决策记录确定。源码路径不可当安装位置。
- 不修改系统 Python、Homebrew、全局包、正式服务或用户安装；新 UI 在实现前完成必要原型确认。
