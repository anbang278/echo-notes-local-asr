# Python / MLX 推理

本文件是本项目已确认的工程约束；尚无应用源码，不能从规范推断功能已实现。

## Pre-Development Checklist

读取 [项目规则](../../../AGENTS.md)、[研发交付约定](../../../docs/DEVELOPMENT.md) 和当前任务，核实相关源码、授权与未验证项。

## 约束

- 首期只验证 Qwen3-ASR-0.6B-8bit 的录音文件普通转写。实时听写、说话人分离、对齐和 1.7B 不作为首期依赖。
- 上游复用固定提交，迁入前记录来源、文件范围和版权；先解除硬编码路径，再考虑重写。依赖锁定到可复现组合。
- Python 环境与用户系统隔离。可搬运 .venv 不是自包含运行时的证据；解释器、原生扩展、动态库与音频解码器均需验证。
- 上传、解码和任务存储有界；音频不在内存中无界累积，不静默截断。错误与取消返回可解释状态并清理临时音频。
- 明确区分模型文件、CPU RSS、MLX 分配和系统统一内存压力。记录冷／热启动、RTF、swap 与音频哈希。
- Mock 仅证明控制流；实际质量、长录音和跨 Mac 兼容需真实样本与设备。进程重启后的重新上传不能写成断点续算。

## Quality Check

逐项核对当前改动及任务测试证据；同步任务、README 与相关设计，缺证据项明确保留为未验证。
