# M0 验证矩阵

| 场景 | 通过标准 | 证据 |
| --- | --- | --- |
| 固定来源 | commit、迁移文件、blob 和版权核对一致 | SOURCE_BASELINE 与组件表 |
| 初始化检查 | bash scripts/check.sh 成功 | 命令与结果 |
| 短录音真实推理 | 固定 0.6B 模型从许可音频得到非空、可人工对照文本 | 音频 SHA-256、模型 revision、时间与人工对照 |
| 干净 Mac | 无全局开发依赖、无既有缓存仍可运行 | 设备清单、依赖审计、首次运行记录 |
| 断网 | 模型完整后启动、加载、解码和推理无网络依赖 | 网络隔离方法与实际结果 |
| 缺模型／组件损坏 | 明确失败，不隐式下载、不回退云端 | 错误与恢复说明 |
| 中文／空格／移动路径 | 移动运行包和模型根后工作正常 | 路径类型与命令，不公开个人绝对路径 |
| 动态库与架构 | arm64 库和解释器匹配，无开发机硬编码路径 | 库清单与检查输出摘要 |
| 签名／公证 | 有证书时验证签名、公证和下载后首启 | 实际命令、票据／结果；无条件就记阻塞 |
| 资源与取消 | 记录内存、RTF、临时音频清理和真实取消行为 | 采样方式、结果及限制 |
| 隔离 | 未停止或更新旧服务、配置、缓存及旧仓库 | 前后状态记录 |
| 交付一致性 | 源码、版本、包哈希与测试安装对应 | delivery manifest 与人工操作说明 |

每项记录预期、实际、PASS / FAIL / BLOCKED / NOT_RUN 及证据位置。Mock 不可替代真实推理、干净设备或签名证据。长录音和完整 GUI 本次只列后续验收入口。
